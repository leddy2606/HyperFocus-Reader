# HyperFocus

**One word. Zero distractions.**

HyperFocus is a distraction-resistant RSVP speed reader. Paste text, press **Go**, and read one word at a time while the optimal recognition point stays anchored at the centre of the screen.

## Features

- 100–1,200 words per minute
- Fixed red optimal recognition point
- Natural punctuation pauses
- Dark and light reading modes
- Adjustable font weight
- Mouse-wheel and keyboard speed controls
- Progress and estimated time remaining
- Fullscreen mobile-friendly reader
- Clipboard paste support
- No account, backend, tracking or installation

## Controls

| Control | Action |
|---|---|
| Space | Pause / play |
| Left / Right | Move one word |
| Ctrl + Left / Right | Jump ten words |
| Up / Down | Change speed |
| Mouse wheel | Change speed |
| F | Fullscreen |
| Esc | Exit reader |

## How it works

HyperFocus uses Rapid Serial Visual Presentation (RSVP), showing one word at a time so the reader does not need to scan across lines. Each word is positioned around an optimal recognition point highlighted in red.

HyperFocus is a reading tool, not a medical treatment or diagnostic product.

## Built with

Plain HTML, CSS and JavaScript. No frameworks and no build process.
